# سياسة سنع للمحتوى العام وحماية الملكية الفكرية

**الحالة:** معتمدة داخليًا  
**النطاق:** المقالات، الفيديو، الصفحات العامة، المنشورات، الدورات، المقابلات، والمواد التسويقية  
**القاعدة الحاكمة:**

> **المحتوى يكشف للعميل مشكلته، ولا يكشف له محرك سنع الذي اكتشفها**

## الطبقة العامة — Public Knowledge

يجوز نشر:
- المشكلة التي يعيشها صاحب الشركة
- الأعراض والآثار المالية والتشغيلية
- الأخطاء الشائعة
- أسئلة عامة تساعد المدير على التفكير
- مؤشرات عامة معروفة مثل CAC وLTV وROAS وConversion Rate
- أمثلة عامة
- ما الذي يستحق الانتباه والنتيجة التي ينبغي الوصول إليها

## الطبقة الخاصة — SANA IP

لا تنشر:
- ترتيب التشخيص أو خطوات الفحص الداخلية
- الأوزان وScoring والمعادلات الخاصة
- الخوارزميات وبوابات القرار وقواعد الانتقال
- Decision Trees أو تسلسل المحركات
- طريقة استخراج الأولوية أو ربط الأدلة بالقرار
- Prompts والنماذج وSOPs التشغيلية الداخلية
- طريقة تحويل الحالة إلى قاعدة أو Pattern أو Benchmark داخل سنع

## فلتر النشر

قبل اعتماد أي مادة عامة نسأل:

> **لو جمع منافس أفضل 100 مقال نشرناها، هل يستطيع إعادة بناء طريقة عمل Sana Scan أو أحد محركات سنع؟**

إذا كانت الإجابة **نعم أو ربما** يعاد تحرير المادة قبل النشر

## دورة التحرير

Backlog → Draft → IP Review → SEO Review → Approved Public → Published → Knowledge Mirror

## العلاقة مع Knowledge OS

المحتوى المنشور يعود إلى Knowledge OS كـ **CONTENT_REFERENCE** للاستفادة منه في:
- شرح المفاهيم بلغة العميل
- صناعة المحتوى
- البحث الموضوعي العام

ولا يستخدم وحده كـ:
- Evidence خاص بالعميل
- Benchmark
- سبب جذري
- قاعدة تشخيص
- قرار عن شركة بعينها

## قاعدة SEO

التركيز على نية البحث ولغة صاحب الشركة والقيمة والنتيجة

قبل إنشاء مقال جديد تراجع المقالات المنشورة لتجنب تكرار النية أو **Keyword Cannibalization**

## خريطة المحتوى

خريطة الـ100 موضوع محفوظة داخل Knowledge OS كـ **CONTENT_BACKLOG** داخلي وليست 100 صفحة تنشر تلقائيًا

كل موضوع يكتب وينشر فقط بعد مروره بفلتر الملكية الفكرية ومراجعة SEO
