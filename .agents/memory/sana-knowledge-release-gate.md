بصمة وسجل الإصدار المعتمد غير قابلين لإعادة الكتابة: أي تغيير للمحتوى أو إعادة استخدام رقم إصدار سبق تسجيله بحالة أخرى يجب أن يطلب إصدارًا جديدًا صراحةً.

**Why:** تحديث البصمة أو حالة المراجعة عبر معالجة التعارض يخفي انجراف المصدر ويعيد كتابة سجل التدقيق لإصدار يبدو ثابتًا رغم تغيّر مادته.

**How to apply:** اجعل إدراج الإصدارات المعتمدة append-only، وارفض اختلاف البصمة أو إعادة استخدام رقم مسجل غير معتمد، وتأكد أن التهيئة المتكررة لا تغيّر سجل الإصدار.
