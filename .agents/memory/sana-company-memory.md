---
name: Sana company memory
description: Durable rules for current values, history, conflicts, retrieval, and privacy in company memory.
---

Company memory is an additive, tenant-private projection over source records. Preserve every version; only a verified, fresh, non-conflicting version may become the current reusable value.

**Why:** Replacing history or silently reusing stale/self-reported information turns old context into false current truth. New contradictory information must remain reviewable rather than winning by recency.

**How to apply:** Write from the original evidence, case, decision, execution, and impact paths. Return provenance, period, verification, freshness, and separate confidence reasons. Discovery prefill requires explicit confirmation before becoming a new answer. Client learning never becomes general Sana Knowledge without de-identification and explicit human review.
