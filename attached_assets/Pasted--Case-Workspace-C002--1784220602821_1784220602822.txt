"نظام تشغيل المحتوى القانوني" (Legal Content Operating System - LCOS)

ضعها ضمن مرحلة "الإنتاج (محتوى + هوية رقمية)" في /case/CS002، كوثيقة منهجية مرجعية يبنى عليها كل محتوى مستقبلي للمكتب. المحتوى كالتالي:

الرؤية:
المحتوى لا يهدف لزيادة المشاهدات أو المتابعين، بل لبناء الثقة وإثبات الخبرة وجذب العملاء المؤهلين. كل فيديو أو مقال أو تصميم أو إجابة قانونية هو أصل معرفي يخدم المكتب لسنوات ويمكن قياس أثره.

فلسفة النظام:
بدل النمط التقليدي (معلومة → منشور → نشر → ينتهي)، يعمل المكتب وفق مسار سنع:
مشكلة قانونية → هدف تجاري → مرحلة رحلة العميل → رسالة قانونية → إنتاج المحتوى → بناء الثقة → التواصل مع المكتب → التعاقد → الرعاية القانونية → الإحالات.

رحلة العميل الخمس مراحل (لكل مرحلة هدف ونوع محتوى):
1. يراك (الهدف: التعريف بالمكتب) — معلومات قانونية، حقوق العملاء، أخطاء قانونية، تحديثات الأنظمة.
2. يثق (الهدف: إثبات الخبرة) — شرح القضايا التجارية، العقود، الحوكمة، إدارة المخاطر، خبرة المحامي، المنهجية القانونية.
3. يتواصل (الهدف: تشجيع التواصل) — متى تحتاج محاميًا؟ هل عقدك يحميك؟ هل شركتك معرضة لمخاطر؟ تقييم قانوني أولي، مراجعة العقود.
4. يشتري (الهدف: التحويل لمتعاقد) — خدمات المكتب، الرعاية القانونية، آلية العمل، خطوات التعاقد، مزايا الاشتراك السنوي.
5. يبقى ويوصي (الهدف: الحفاظ على العميل) — تحديثات الأنظمة، نشرات قانونية، تنبيهات تشريعية، نصائح دورية، قصص نجاح، برامج الإحالة.
