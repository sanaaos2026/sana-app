# SANA PRODUCT & KNOWLEDGE CORE
## المرجع الحاكم لمنصة سنع

**الحالة:** معتمد كمرجع تشغيلي ومعرفي
**الاستخدام:** Replit + Sana Knowledge Brain + Drive Index
**القاعدة:** لا ميزة جديدة إلا إذا أغلقت فجوة حقيقية مثبتة.

---

# 1. تعريف سنع

**سنع — Sana** هو نظام تشخيص وقرار للنمو.

الوعد الأساسي:
> **وضوح يصنع النمو**

سنع لا يهدف إلى عرض أكبر كمية من المعلومات، ولا إلى إنتاج تقرير AI، ولا إلى أن يكون Dashboard مزدحمًا.

سنع يحول:
**بيانات + أدلة + معرفة سنع → تشخيص → أولوية → قرار → تنفيذ → قياس أثر → تعلم**

الصياغة المختصرة:
> **سنع يرى ما لا تراه في شركتك، ويحدد أين المشكلة، لماذا، وما القرار الأعلى أولوية الآن.**

---

# 2. المبادئ الحاكمة

1. وضوح > كثرة المعلومات
2. دليل > رأي
3. قرار > تقرير
4. خطوة تالية > قائمة ميزات
5. أثر > نشاط
6. أسئلة أذكى > أسئلة أكثر
7. لا Finding مهم بلا دليل
8. لا سؤال إلا إذا غيّر التشخيص أو القرار
9. لا Score بلا معادلة موثقة
10. لا Confidence تجميلي
11. لا Decision معتمد بلا Owner + Deadline + KPI + Next Action
12. لا إعادة بناء لما يعمل
13. لا نظام جديد إلا إذا أغلق فجوة حقيقية
14. لا يظهر للعميل ما لا يحتاجه لاتخاذ القرار
15. AI ليس عقل سنع؛ Knowledge + Evidence + Rules هي العقل
16. سنع لا يعرض كل ما يعرفه؛ يعرض أقل قدر من المعلومات الذي يجعل القرار أوضح

# 9. دور AI

يسمح للـAI بـ:
- فهم لغة العميل
- استخراج البيانات
- تصنيف المعلومات
- البحث داخل مكتبة سنع
- اقتراح التطابقات
- تلخيص الأدلة
- تحسين الصياغة
- تبسيط العرض

لا يسمح له باختراع:
- Root Cause
- KPI
- Benchmark
- Diagnostic Rule
- Decision Rule
- Financial Value
- Recommendation بلا سند

إذا لم توجد معرفة كافية:
> لا توجد أدلة أو معرفة كافية لاتخاذ هذا القرار.

ثم:
- Missing Evidence
- Next Question
- Research Required
- Consultant Review

# 10. Drive + Sana

**Google Drive** = المصدر الأصلي + ملفات العملاء + الأدلة + الوثائق + التقارير + النسخ المرجعية + الأرشيف

**Sana Database** = الكيانات المنظمة + الحقائق + الفرضيات + الأدلة + القرارات + KPIs + العلاقات

**Sana Knowledge Brain** = القواعد + الأنماط + الحالات المجردة + SOPs + المعرفة القابلة لإعادة الاستخدام

**Replit** = التطبيق + المنطق + الواجهات

**AI** = فهم + استخراج + تصنيف + صياغة

# 14. خارطة الإصدارات

## P0 — حلقة الوضوح
فهم الشركة → البحث → الفرضيات → الأسئلة → الأدلة → Sana Scan → أهم اختناق → قرار → خطوة تالية.

## P1 — ذكاء التشخيص
Root Cause + KPI Registry + Diagnostic Rules + Confidence + Contradiction + Traceability.

## P2 — العرض والتموضع والتسعير
Offer + Positioning + Packaging + Pricing + Margin + Value.

## P3 — حلقة التنفيذ
Decision → Owner → Deadline → Task → KPI → Evidence → Review + SOP.

## P4 — إثبات القيمة
Baseline → Target → Actual → Revenue/Cost/Time/Impact.

## P5 — المبيعات والإيراد
Sales Math + Pipeline + Qualification + Follow-up + Close Rate + Revenue Leakage.

## P6 — رحلة العميل والاحتفاظ
Journey + Leakage + SLA + Handoffs + Retention + Expansion + Referral + LTV.

## P7 — الذكاء القطاعي
Sector KPIs + Benchmarks + Problems + Causes + Questions + Cases + SOPs.

## P8 — نظام تشغيل الفريق
Users + Roles + Accountability + Weekly Review + Approvals + Executive View.

## P9 — الفرص والصفقات
Opportunity Signal + Qualification + Deal Structure + Relationship Intelligence + Next Best Action.

## P10 — الاستثمار والجدوى
Investment Conviction + Assumptions + Risk + Simulation + Test + Capital Protection + Exit.

## P11 — قيمة الشركة + Sana Growth OS
Revenue Quality + Recurring Revenue + Assets + Data + Brand + SOPs + Founder Dependency + Scalability + Exit Readiness.

# 17. القاعدة النهائية

> سنع ليس مكتبة أدوات.
> سنع ليس Dashboard.
> سنع ليس تقرير AI.
> سنع نظام يحول البيانات والأدلة إلى وضوح، والوضوح إلى قرار، والقرار إلى تنفيذ، والتنفيذ إلى أثر، والأثر إلى معرفة متراكمة.

**سنع — وضوح يصنع النمو.**
